# CprE 487/587 Lab 7 — Custom Hardware Accelerator

Iowa State University · CprE 487/587 · Lab 7 · Team 06

A ZedBoard accelerator for one convolutional layer with built-in 2×2 max pooling; because the same hardware handles a dense layer, the whole model except the final softmax can run on it. The handout is [`CprE487_587_Lab7.pdf`](CprE487_587_Lab7.pdf).

## Template facts worth remembering

- Five BRAM interfaces: one 32-bit input word and up to four 32-bit weight words per read; read data is valid the cycle after the address and enable are set.
- Two activation banks swap input and output with one pin, so layer outputs become the next layer's inputs without copying. Four double-buffered weight BRAMs let the DMA load the next weights while the accelerator runs.
- The processor cannot touch the BRAMs; every copy goes through the CDMA. The data cache is disabled (`Xil_DCacheDisable()`) because the DMA is not cache-coherent.
- The template feeds 4 MAC units with 1 input byte and 4 weight bytes per cycle (4 output channels in parallel); weights must be transposed so the output channel is the most significant dimension.
- MACs take the bias from a 32-bit bus on the first accumulation after reset or TLAST (no TUSER).
- Output stores are 8-bit read-modify-write on 32-bit BRAM words; 3 or more cycles per store is enough.
- The template accelerator completes a full model inference in under 300 ms.
